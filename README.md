# EC Research Studio v1.1

## Electronic Lab Notebook
- Experiment별 ELN entry 작성
- Protocol / observation / result / next action 기록
- 이미지, PDF, CSV, Excel, TXT 첨부
- Notebook history 조회
- Markdown export
- Entry 삭제
- 기존 실험 정보 자동 불러오기

## 실행
```bat
python -m pip install -r requirements.txt
streamlit run main.py
```
