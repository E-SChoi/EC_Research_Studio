# EC Research Studio v1.4 Stable

## Stable release fixes
- Fixed the `main.py` import syntax error from v1.3
- Verified Python syntax for the full project
- Preserved all v1.3 features
- Added a stable release label

## Included features
- Today workspace
- Result Viewer
- Batch status
- Figure gallery
- Rule-based Discussion draft
- DPV / SWV / EIS / CV analysis
- Statistics
- Figure Builder
- Electronic Lab Notebook
- Database
- Backup and export

## Apply
1. Stop Streamlit with `Ctrl + C`
2. Extract the full ZIP or patch ZIP
3. Overwrite the existing project files
4. Run:

```bat
streamlit run main.py
```
